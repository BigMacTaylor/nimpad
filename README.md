# Nimpad

A very simple text editor with theme support and syntax highlighting.
Written in Nim, you can use it as is, or as a building block for your own IDE.

## Installation

### Debian/Ubuntu

Download the `.deb` file from the [releases page](https://github.com/BigMacTaylor/nimpad/releases) and

```bash
sudo apt install ./nimpad_*.deb
```

### Fedora

Download the `.rpm` file from the [releases page](https://github.com/BigMacTaylor/nimpad/releases) and

```bash
sudo dnf install ./nimpad*.rpm
```

## Keybinds

| Section | Action | Key |
|---|---|---|
| **File** | Save | `Ctrl` + `s` |
| | Save As | `Ctrl` + `Shift` + `s` |
| | Copy | `Ctrl` + `c` |
| | Cut | `Ctrl` + `x` |
| | Paste | `Ctrl` + `v` |
| | Duplicate | `Ctrl` + `d` |
| | Undo | `Ctrl` + `z` |
| | Redo | `Ctrl` + `Shift` + `z` |
| | | |
| **Search** | Find | `Ctrl` + `f` |
| | Grab Next Match | `Ctrl` + `g` |
| | Grab Previous Match | `Ctrl` + `Shift` + `g` |
| | Replace | `Ctrl` + `r` |
| | Move to Word Left | `Ctrl` + `←` |
| | Move to Word Right | `Ctrl` + `→` |
| | Jump to Line | `Ctrl` + `j` |
| | | |
| **Select** | Select All | `Ctrl` + `a` |
| | Unselect All | `Ctrl` + `Shift` + `a` |
| | Select Word | `Ctrl` + `w` |
| | Select Word Left | `Ctrl` + `Shift` + `←` |
| | Select Word Right | `Ctrl` + `Shift` + `→` |
| | Select Line | `Ctrl` + `l` |
| | Unselect Line | `Ctrl` + `Shift` + `l` |
| | Select Line Up | `Ctrl` + `Shift` + `↑` |
| | Select Line Down | `Ctrl` + `Shift` + `↓` |
| | | |
| **General** | Move Line Up | `Alt` + `↑` |
| | Move Line Down | `Alt` + `↓` |
| | Preferences | `Ctrl` + `,` |
| | Shortcuts | `Ctrl` + `?` |
| | Quit | `Ctrl` + `q` |
